# Compresión Multimedia - Facultad de Informática (UMU)

Este repositorio contiene las prácticas y trabajos desarrollados para la asignatura de Compresión Multimedia en la Facultad de Informática de la Universidad de Murcia. El proyecto incluye implementaciones en MATLAB orientadas al estudio y aplicación de algoritmos de compresión con y sin pérdida para diferentes tipos de medios.

## Contenidos

El código está organizado según las unidades temáticas de la asignatura:

- **Compresión de Datos:** Algoritmos de codificación de fuente (Huffman).
- **Transformadas:** Análisis de señales mediante la Transformada Discreta del Coseno (DCT).
- **Compresión de Imagen:** Implementación de esquemas basados en el estándar JPEG (cuantificación, escaneado zig-zag y codificación).

## Estructura del Proyecto

- `/source`: Código fuente de las funciones y scripts principales.
- `/doc`: Documento de texto desarollado para el proyecto
