## README

Este directorio contiene:

- Todos los ficheros **.m** necesarios para los procesos de **compresión** y **descompresión**, cada uno ampliamente comentado para garantizar una comprensión clara de su funcionamiento.
- Todos los ficheros originales **.BMP** utilizados durante el desarrollo de la práctica: Ubicados en ./images.
- Para cada imagen BMP, se incluyen **tres versiones comprimidas**, generadas a partir de **tres factores de calidad** previamente fijados: ./data.

La documentación se encuentra en ../doc
